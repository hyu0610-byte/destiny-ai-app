# 지표 설계 (미션 9-1)

Destiny AI MVP의 핵심 사용자 흐름은 다음과 같다.

```
홈(랜딩) → 정보 입력 → 해석 모드 선택 → 결과 확인(AI 해석)
                                              ↕
                                   회원가입/로그인 → 히스토리
```

이 흐름에서 "유입"과 "핵심 행동(사주 결과까지 도달)"을 측정할 수 있는 최소 지표 체계를 아래와 같이 정의한다.

## 핵심 지표

| # | 지표명 | 정의 | 왜 중요한가 | 측정 방법 |
|---|---|---|---|---|
| 1 | **방문자 수 (Visitors)** | 홈페이지(`/`)에 도달한 순 사용자 수 | 전체 유입 규모와 채널별 효과(UTM)를 가늠하는 기준 지표 | GA4 기본 리포트 / Amplitude `page_view` 이벤트의 unique user 수 |
| 2 | **사주 결과 도달률** | `saju_input_submitted` 발생 사용자 중 `result_viewed`까지 도달한 비율 | 서비스의 핵심 가치(AI 사주 해석)까지 사용자가 실제로 도달하는지 보여주는 핵심 기능 사용률 지표. 이탈이 큰 구간을 역으로 찾아낼 수 있음 | Amplitude Funnel (`saju_input_submitted` → `mode_selected` → `result_viewed`) |
| 3 | **회원가입 전환율** | 전체 방문자(`page_view` unique user) 중 `signup_completed`까지 도달한 비율 | 비로그인으로도 결과를 볼 수 있는 구조라, 회원가입은 "재방문·히스토리 저장 가치"를 느낀 사용자만 하는 자발적 행동 — 서비스 매력도의 간접 지표 | Amplitude Funnel / GA4 전환 이벤트 |
| 4 | **해석 모드별 선택 비율** | `mode_selected` 이벤트의 `mode` 속성별 분포(전통 사주 / 오늘의 운세 / MZ 타로) | 어떤 해석 컨셉이 더 선호되는지 파악 → 향후 콘텐츠·마케팅 방향 결정에 활용 | Amplitude 이벤트 속성(Property) 분포 차트 |

## 다음 단계와의 연결

- 지표 2(사주 결과 도달률)는 퍼널 분석의 기준이 되며, 단계별로 어디서 이탈이 생기는지(입력 포기 / 모드 선택 후 이탈 / AI 해석 실패로 인한 이탈)를 **로그 설계**에서 세분화해 추적한다.
- 지표 1·3은 **UTM 파라미터**와 결합해 채널별 유입량·전환율 비교에 사용한다.
